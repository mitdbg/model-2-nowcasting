How It Works

Model 2 works in three stages. First, choose a world: the entities, observations and sector data the model can see. Second, run the model at a date T, using only what was known at T: estimate the parameters, re-estimate the history, estimate month T and forecast the next 12 months. Third, score the results: against the true values in a synthetic world, or against what is published later in the real world. A backtest repeats the second and third stages at a series of past dates.

Click a box to see its tables in the Data Model.

1 · Choose a world

A world is everything the model can see:

  • The entity registry lists the entities, their sites, the companies that own or operate them, and the groupings that observations are about. Every fact carries dates, so the set changes over time: an entity can be planned, built, go idle or close, and a company can sell a plant. Each run uses the entities active on its date, as the registry knew them then.
  • Observations are published readings about an entity or a grouping, each with the date it became public.
  • The sector input bundle arrives once per run date with each sector's drivers (demand, price, input cost) and statistics, as ensemble draws.

A synthetic world is generated from known parameters, so it comes with the true values of every hidden state; the model never sees them. A real world is built from public sources and has no such truth. The current synthetic world keeps the same entities throughout, with one change of ownership in 2019.

2 · Run at each date T

A run is self-contained and uses only what was known at its date T:

  1. Gather the registry as recorded by T, the observations published by T, and the input bundle for T.
  2. Estimate the parameters from the history up to T, once a quarter for each sector. Later runs in the same quarter reuse those parameters.
  3. Filter and forecast with the parameters fixed: re-estimate the months before T (history), estimate month T (nowcast), and project 12 months ahead (forecast). Forecasts follow the sector drivers alone, since no observations exist yet for those months. The ensemble of 100 draws gives every quantity a 90% band.

The next run date sees the new observations and starts again, so the history, nowcast and forecast all move as information arrives.

3 · Score

  • In a synthetic world, every output can be scored against the true values: sector totals, entity states and the parameters themselves. The Accuracy tab shows these scores.
  • In the real world, hidden states such as a plant's capacity or order book are never observed, so they cannot be scored. Anything published later can be: a forecast of a sector statistic, a company filing or a census count can be compared with the value once it appears. This scoring is not built yet.

Backtests

A backtest repeats stages 2 and 3 at a series of past dates. Each run sees only what was known on its date, as if it had run then, so its errors show how the model would have done in real time. The scores cover the last 12 months of history, the nowcast, and forecasts 3, 6 and 12 months ahead.
