Hidden states

Each chart shows the median and unwidened 90% band of the filter's estimate for this operation, with the truth (dashed). Shading marks nowcast and forecast months. The ⓘ button defines each quantity.

Observations against the model

Each chart compares one type of observation with the model's prediction of it. Dots: observed values. Line: predicted value. Band: prediction plus the observation's own noise, which should hold about 90% of the dots; red dots fall outside it. Company-level observations cover several operations, so the model predicts their sum over the company's operations.

Fitted parameters

Each row shows one free parameter of this operation. Bar: the prior's 90% interval (grey), the fit's 90% interval (outlined), the fitted value and the truth (orange tick). Sd ratio: the fit's sd over the prior's; near 1, the data taught little. Offsets such as õ and α count from window constants (D̄, x̄, log K₀) that the fit sets from its own window, so fit and truth can differ by convention as well as by error.
