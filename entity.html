Entity

Groupings

Groupings are the companies, segments, sites and Census cells that contain this entity. An observation about a grouping covers all its entities at once, each at its weight, so the model predicts it from their combined states.

Hidden states

Hidden states are the quantities Model 2 estimates for this entity each month: capacity, output, order book, price and the rest. The model never sees their true values. Observations measure them only indirectly or imperfectly: with noise, weeks or months late, for some months only, and often summed over all of a company's entities. Some states, such as finished inventory, have no observation at all, and the model's dynamics alone carry them. The ensemble filter combines the dynamics with whatever observations exist into an estimate with a 90% band.

Each chart shows the median and unwidened 90% band of that estimate, with the truth (dashed), which only the synthetic world knows. Shading marks nowcast and forecast months. The ⓘ button defines each quantity.

Observations against the model

Observations are the opposite of hidden states: the model never sees the states, but it sees every observation exactly as published. Each observation is a number from an outside source (a company filing, a satellite reading, a Census count) that depends on hidden states. Model 2 predicts each observation from its state estimates, and the gap between prediction and observation is how the data correct the states. A model that tracks the states well predicts its observations well, so these charts test the model against what it can see, while the truth lines above test it against what it cannot.

Each chart compares one type of observation with the model's prediction of it. Dots: observed values. Line: predicted value. Band: prediction plus the observation's own noise, which should hold about 90% of the dots; red dots fall outside it. An observation about a grouping covers several entities, so the model predicts it from their combined states.

Fitted parameters

Each row shows one free parameter of this entity. Bar: the prior's 90% interval (grey), the fit's 90% interval (outlined), the fitted value and the truth (orange tick). Sd ratio: the fit's sd over the prior's; near 1, the data taught little. Offsets such as õ and α count from window constants (D̄, x̄, log K₀) that the fit sets from its own window, so fit and truth can differ by convention as well as by error.

A parameter is a number in the model, not something a firm reports. The truth exists only because the synthetic world is generated from the model's own equations: the simulation draws each entity's parameters, then runs the dynamics with them. Recovering them shows that the fitting works when the model is right; it does not show that the model is right. On real data there is no truth column.
