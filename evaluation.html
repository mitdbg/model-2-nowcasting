Without Ground Truth

Measures of quality that need no ground truth, so they work on a real world as well as a synthetic one. Like observations against the model and sector totals against official statistics, they check how well the model fits data it has used, which is a weaker test than forecasts against later estimates, since a model always looks better on data it has seen.

What the data pin down

How much the data narrowed what the model knew before seeing them. For entity parameters, the share whose uncertainty the fit cut by at least a fifth (sd ratio below 0.8). For sector totals, the quantities whose estimate is still mostly prior (posterior over prior variance above 0.8): no observation reaches them, so the equations alone carry them.
