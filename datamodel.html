Data Model

Model 2 works with six families of related tables. The entity registry records what exists and who owns what on any date. Observations are the published readings the model learns from, each about an entity or a grouping. The sector input bundle supplies each sector's drivers and statistics as ensemble draws. Settings and fitted parameters steer the model, and each run produces sector totals, entity states and diagnostics for its run date. In a synthetic world, the true values and backtest scores sit beside them. Click a table to see its columns, its key and how it joins to the others; the notes in amber say where a rule is not checked or the meaning is unclear.
