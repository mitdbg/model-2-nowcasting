Data Model

Model 2 works with eight families of related tables. The entity registry records what exists and who owns what on any date. Observations are the published readings the model learns from, each about an entity or a grouping. The sector input bundle supplies each sector's drivers and statistics as ensemble draws. Configuration holds the settings people choose; parameter fitting holds the parameters estimated from past data. Each run produces sector totals, entity states and diagnostics for its run date. Synthetic truth holds the true values behind a synthetic world and exists only there; scores record how close each run came. Click a table to see its columns, its key and how it joins to the others; the notes in amber say where a rule is not checked or the meaning is unclear.
