Data Model

Model 2 works with ten families of related tables, in five phases. Over all of them, the catalog keeps a lasting record of every world, model version, fit and forecast. The entity registry records what exists and who owns what on any date. Observations are the published readings the model learns from, each about an entity or a grouping. The sector input bundle supplies each sector's drivers and statistics as ensemble draws. Configuration holds the settings people choose; parameter fitting holds the parameters estimated from past data. Each run produces sector totals, entity states and diagnostics for its run date. Synthetic truth holds the true values behind a synthetic world and exists only there; scores record how close each run came. To improve the system, problems and possible fixes record what the evaluation of a forecast found wrong and what might fix it, and the testing plan and test results record which fixes were tested and what each test found; each has an id that never changes and names its world, fit and forecast. A world's own tables are keyed only within the world, so their rows are unique together with the world's id. Click a table to see its columns, its key and how it joins to the others; the notes in amber say where a rule is not checked or the meaning is unclear.
