# Overview of World 844151cd-89f8-5a64-b12b-f31f12603eaf

A world is everything Model 2 is allowed to know. Every forecast is made inside one world, and sees only what that world had published by the forecast's as-of date.

A world has three kinds of input:

- Entities: the businesses the model follows, such as plants, stores, data centers and hospitals, and the companies that own or run them. Some are tracked one by one. Others are representative entities, each standing in for many small establishments of one size and region that are not tracked individually. Every fact carries dates, so entities can open, close or change hands.

- Observations: scattered public readings about those entities or groups of them, such as a quarterly filing, an announced plant, a stated capacity, a price list or an emissions report. Each is dated by when it became public.

- The sector input bundle: a delivery from an outside source for each as-of date. For every sector it brings drivers, such as demand, price and input cost, which influence the entities' activity. It also brings official sector statistics, which constrain the entities' total.

What a world does not show is just as important. Each entity's capacity, order book, costs and other hidden quantities are never observed directly; estimating them is the model's job.

The model configuration is an input too, but it belongs to the model, not the world. It holds fixed values and starting ranges chosen by people, and the same configuration can be run on many worlds.

Synthetic and real worlds. A synthetic world is generated by a simulation, using Model 2's own equations and parameters we choose. Its entities, companies and observations are invented, but its sectors, sizes, data sources and publication schedules imitate real ones. Because the simulation knows the true value of every hidden quantity and parameter, forecasts on a synthetic world can be scored exactly. That is how we test whether the model can recover what generated the data. A different random seed draws a different world under the same rules. A real world is built from public sources. No one knows its hidden quantities, so its forecasts can be scored only against figures published later. Every world so far is synthetic.

This world is synthetic: seed 20261107, generated 2026-11-10, with the model's own equations.
